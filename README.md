# My Daily Routine — YV English

Projeto completo em React da atividade interativa da YV English.

## Requisitos

- Node.js 22.13 ou superior
- npm

## Executar no computador

Abra o terminal dentro da pasta do projeto e rode:

```bash
npm install
npm run dev
```

O terminal mostrará o endereço local da página. Use `Ctrl + C` para encerrar.

## Criar a versão de produção

```bash
npm run build
```

## Principais arquivos

- `app/page.tsx`: conteúdo, vocabulário, leitor, perguntas e envio do formulário
- `app/globals.css`: design completo e responsividade
- `app/layout.tsx`: título e metadados
- `public/yv-logo.png`: logo utilizada na página

O projeto já inclui o `package.json` e o `package-lock.json`. A chave do Web3Forms já está configurada em `app/page.tsx`.
